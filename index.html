# BattleChat BattleChat — bilan ishlaydigan blogger battle app. Frontend va backend birga ishlaydi. ## Features - VIP battle screen - admin panel - vote tracking - coins / store flow - Telegram-ready backend integration - JSON-based data persistence ## Run locally 1. Install dependencies: ```bash npm install ``` 2. Start the server: ```bash npm start ``` 3. Open in browser: ```text http://localhost:3000/ ``` ## Telegram bot Create `.env` from `.env.example` and add your Telegram bot token: ```bash cp .env.example .env ``` Then set: ```env PORT=3000 BOT_TOKEN=your_telegram_bot_token_here ``` ## API - `GET /api/health` - `GET /api/battle` - `POST /api/vote` with `{ "blogger": "Doniyor Qayumov" }` - `POST /api/store/buy` with `{ "amount": 50 }` - `POST /api/admin/boost` with `{ "name": "Doniyor Qayumov", "count": 150 }` - `POST /api/admin/reset` ## Notes This is a working prototype. For a production deployment, connect a real database and Telegram webhook config for a hosted server.
